# Cloud 云端工程仓库

集中管理个人工程项目、共享资源和开发文档。

## 目录结构

- `projects/`：独立工程，每个工程使用自己的子目录。
- `shared/`：多个工程共用的代码和资源。
- `docs/`：仓库级文档和设计记录。
- `scripts/`：仓库级自动化脚本。

## 添加工程

1. 在 `projects/<工程名称>/` 中创建或放入工程。
2. 为工程添加 README，说明用途、运行环境、安装、启动和测试命令。
3. 将依赖声明和锁文件随工程提交，保持各工程可以独立开发。
4. 提交代码并推送到 GitHub。

请勿提交密码、访问令牌、私钥、真实环境变量文件或敏感业务数据。使用 `.env.example` 记录变量名称和非敏感示例值。

仓库尚未包含具体应用，因此暂时没有统一的依赖安装、启动或测试命令。
